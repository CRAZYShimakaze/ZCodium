# ZCodium v1.17.1

## 本次更新

这是 v1.17.0 的补丁发行，只修复 macOS 安装包布局与发布构建链路，不新增功能。

### 1. 修复 macOS DMG 安装界面

v1.17.0 的 DMG 里，ZCodium 图标与 Applications 链接使用了 electron-builder 的默认坐标，压在背景安装说明文字上；两个解除拦截说明文件也没有被打进 DMG。原因是 2026-10 的上游同步整体覆盖了 `dmg.contents`，而自定义的 620x560 背景图仍然保留。

- 恢复与背景图配套的图标坐标：应用图标 (150, 120)、Applications 链接 (470, 120)，说明文字完整可见。
- `解除拦截.txt` 与 `Unblock.txt` 重新随 DMG 分发，分别位于背景箭头下方 (170, 370) / (450, 370)。
- 新增 DMG 布局契约测试，锁定背景尺寸、图标坐标、说明文件落点与命令内容，防止后续同步再次回退。

本次发行前已实际挂载本次构建的 arm64 DMG：窗口 620x560，图标不再遮挡文字，两个说明文件都存在。

### 2. 修复发布构建的版本注入

恢复 `ZCODE_APP_VERSION` 在构建元数据、远端资源目录和 runtime manifest 中的优先级，确保预发布与正式版的产物版本、更新清单与 tag 一致；本地开发仍回退到 `package.json` 版本。

### 验证范围

- DMG 布局、构建元数据版本、远端资源 staging 相关测试：16 项通过。
- 根 `pnpm typecheck` 通过；Lint 0 errors（117 个既有 warning）；格式检查通过。
- macOS arm64 DMG 已实际挂载核对布局与说明文件；其他平台安装包未逐个启动验收。
- 未执行全量单元测试，也未做 Windows/Linux GUI 实测；本次补丁不宣称这些范围通过。

## 下载与安装

| 平台                | 文件                                     |
| ------------------- | ---------------------------------------- |
| macOS Apple Silicon | `ZCodium-1.17.1-mac-arm64.dmg` / `.zip`  |
| macOS Intel         | `ZCodium-1.17.1-mac-x64.dmg` / `.zip`    |
| Windows x64         | `ZCodium-1.17.1-win-x64.exe`             |
| Linux x64           | `ZCodium-1.17.1-linux-x86_64.AppImage`   |
| Linux arm64         | `ZCodium-1.17.1-linux-arm64.AppImage`    |
| CLI（Node.js 24）   | `zcodium-1.17.1.tar.gz`                  |

安装包**没有 ZCode 官方签名**。macOS 打开 DMG、把 ZCodium 拖进「应用程序」后，首次打开会被 Gatekeeper 拦截，执行一次：

```bash
sudo /usr/bin/xattr -rd com.apple.quarantine "/Applications/ZCodium.app" && open -a "ZCodium"
```

输入密码时屏幕不显示字符，命令执行完会自动启动。Windows 若出现 SmartScreen 提示，核对来源与 `sha256.txt` 后选择「更多信息 → 仍要运行」。Linux 给 AppImage 执行权限后运行。

## 已知限制

- 远程项目仍只支持单一固定 root；公网手机配对入口未恢复。
- Computer Use 仍为不可用占位；官方账号、购买、分享入口保持下线。
- 安装包未签名，无法避免系统首次启动拦截。

## English summary

Patch release for v1.17.0. Restores the DMG icon coordinates that match the custom 620x560 background (the app icon and Applications link no longer cover the install instructions), ships `解除拦截.txt` / `Unblock.txt` inside the DMG again, and restores the `ZCODE_APP_VERSION` injection so preview and stable artifacts carry the correct version. Verified by mounting the arm64 DMG and running the related layout/version tests; no full test suite or Windows/Linux GUI validation is claimed. Installers are not signed by ZCode.
