# ZCodium v1.17.2

## 重要：macOS 请先手动安装本版

旧版内置的更新地址错误地指向 `localhost:8081`，无法自动获得本次修复。请从本页下载对应架构的 DMG，退出 ZCodium 后拖入「应用程序」并替换旧应用；无需删除用户数据目录。

当前 macOS 发行包未签名，不能使用 Squirrel.Mac 原生自动安装。**本版提供检查新版与明确的手动安装引导，不是恢复 macOS 全自动升级。**

## 本次更新

### 1. 更新检查与 macOS 手动安装（#88）

- 恢复 GitHub Releases 更新源，同时修正运行时初始化和打包配置，避免继续向 localhost 检查更新。
- 稳定版本统一使用 stable 通道；旧 preview 设置不再干扰版本跳过或触发重复检查。
- macOS 发现新版后明确提示“当前版本未签名，无法自动安装”，主按钮为“前往下载并手动安装”。点击打开官方 Releases 页面，请选择 Apple Silicon / Intel 对应的 DMG，退出应用后替换安装。
- 手动安装模式不自动下载、不重启安装，也不因旧缓存显示“重启以更新”；隐藏“自动下载并安装”选项。Windows/Linux 的原生更新流程保持不变。

### 2. Windows 关闭窗口隐藏到托盘（#77）

- 修正主入口传错参数及遗漏托盘能力的问题。
- 设置开启且托盘创建成功时隐藏窗口；关闭设置、托盘不可用或显式退出时不误隐藏。
- 本次只恢复 Windows 行为，不意外启用尚未完整接入的 Linux 托盘驻留功能。

### 3. SQLite schema 兼容门禁（#89）

- 将 app / CLI 两库真实迁移的只增兼容检查接入 pre-push 和相关路径的 PR CI。
- 以目标分支或显式 CI 基线比较，拒绝“删除字段并同步修改 baseline”绕过检查；读取历史失败不再静默跳过。

## 验证边界

专项测试覆盖更新检查、手动下载入口、禁止原生安装/缓存 ready 重放、界面提示与按钮解锁，以及 Windows 托盘和数据库兼容检查。根类型检查、Lint 与增量架构门禁按本次修复范围执行。

没有执行全量单测，也未宣称 Windows/Linux 真机 GUI 或 macOS 原生自动升级通过。macOS 原生自动安装不属于本版承诺的能力。

## English summary

Fixes the update feed accidentally pointing to localhost. Existing users must manually install this release once. Unsigned macOS builds now explicitly guide users to the official Releases page to download the correct DMG and replace the app after quitting; they do not offer native automatic installation or a misleading “Restart to update” action. Windows/Linux native update behavior is unchanged. Also includes the Windows close-to-tray repair and app/CLI SQLite schema compatibility gates. No full test suite or Windows/Linux GUI validation is claimed.
